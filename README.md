# Dungeons2Warden

Dungeons2Warden is a Minecraft plugin that adds an exact replica of the Twisted Warden and the Monarch from Minecraft Dungeons 2. This plugin is designed to enhance your Minecraft server with unique mobs and features inspired by the popular game.

## Install

1. Download the plugin JAR file from the releases section of the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your server to load the plugin.

## Use

1. After installing the plugin, the Twisted Warden and Monarch mobs will be available in your Minecraft world.
2. Use the `/ciao` command to greet yourself or other players.
